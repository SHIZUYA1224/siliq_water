# Siliq Water — 水面ノーマルマップ生成ツール

Unity エディタ上で、水面・水表現向けの**高品質なノーマルマップを手続き生成**するツールです。
生成されるのはただの PNG テクスチャなので、**VRChat のモバイル版 (Quest / Android) でもそのまま使えます**。

![対応] Unity 2019.4 以降 / ビルトインレンダーパイプライン (VRChat 対応)

## 特徴

- **必ずシームレスにタイリング** — 全ノイズをトーラス上で定義しているため、継ぎ目が一切出ません
- **6 種類の波レイヤーを自由に重ねられる**
  - 揺らぎノイズ (パーリン fBm) — 穏やかな水面の基本
  - 尖ったうねり (リッジノイズ) — 荒れた水面
  - ボロノイ・泡 — 丸い盛り上がり、スタイライズ表現
  - ボロノイ・網目 — コースティクス風の網目模様
  - 指向性の波 (ゲルストナー風) — 波頭の尖った海のうねり
  - 雨の波紋 — 広がるリング状の波紋
- **プリセット 6 種** — 穏やかな湖 / 海のうねり / 川の流れ / 雨の水面 / さざ波 / トゥーン
- **リアルタイムプレビュー** — 2×2 タイリング表示・アニメ再生付き
- **完全ループするアニメーション書き出し** — 連番 PNG またはアトラス (フリップブック)
- **Quest 向けインポート設定を自動適用** — NormalMap タイプ / Repeat / Android は ASTC 6x6 圧縮
- **ハイトマップ書き出し**にも対応 (他ツールとの連携用)
- おまけ: Quest ワールド向け軽量水シェーダー `Siliq/Water Mobile (Quest)` を同梱

## インストール

### UPM (Git URL) — 推奨

Unity の `Window > Package Manager > + > Add package from git URL...` に以下を入力:

```
https://github.com/shizuya1224/siliq_water.git
```

### 手動

このリポジトリを丸ごと `Packages/` フォルダ、または `Assets/SiliqWater/` にコピーしてください。

## 使い方

1. メニューの **Tools > Siliq Water > 水面ノーマルマップ生成** を開く
2. **プリセット**から近いものを選んで「適用」
3. プレビューを見ながら**波レイヤー**を追加・調整
   - `スケール` = 模様の細かさ、`振幅` = レイヤーの強さ、`凹凸の強さ` = 全体のノーマル強度
4. **「ノーマルマップを書き出し (PNG)」** で保存 — インポート設定は自動で適用されます

### アニメーションさせたい場合

最軽量なのは **1 枚のノーマルマップを UV スクロール**する方法です (Quest 推奨)。
本格的に波の形を動かしたい場合は「ループアニメを連番 / アトラス書き出し」を使ってください。
全レイヤーの速度が整数で設計されているため、**最終フレームから先頭フレームへ完全にループ**します。

## VRChat モバイル (Quest) での使い方

| 用途 | 方法 |
|---|---|
| **アバター** | Quest アバターはカスタムシェーダー不可のため、`VRChat/Mobile/Standard Lite` の **Normal Map** スロットに生成したマップをセット |
| **ワールド** | カスタムシェーダー可。同梱の `Siliq/Water Mobile (Quest)` に生成したマップをセットすると、1 枚のマップを 2 レイヤーでスクロールさせる動く水面になります |

「Quest 向けインポート設定を自動適用」を ON にしておくと、書き出し時に Android プラットフォームの
テクスチャ圧縮が **ASTC 6x6・最大 1024px** に設定され、Quest のメモリ制限に収まりやすくなります。

## 同梱シェーダー `Siliq/Water Mobile (Quest)`

1 パス・不透明・GrabPass なしの Quest セーフ設計です。

- ノーマルマップ 1 枚を tiling / scroll 違いで 2 回サンプリングして波を合成
- 深い色 ⇔ 浅い色のグラデーション + フレネル反射 + スペキュラハイライト
- 任意でキューブマップ反射 (「キューブマップ反射を使う」を ON)

