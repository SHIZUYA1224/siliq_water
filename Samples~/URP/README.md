# Siliq Water URP Shader Sample

This sample contains the optional `Siliq/Water URP` shader.

Import it only in projects that have Universal Render Pipeline installed. Built-in Render Pipeline, VRChat, Quest, and iOS-focused projects do not need this sample and should use `Siliq/Water Mobile (Quest)`.

Unity import path:

`Package Manager > Siliq Water Maps Studio > Samples > URP Shader > Import`
